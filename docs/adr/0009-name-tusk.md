# 0009. The browser is called Tusk

Date: 30 Oct 2026 · Status: Proposed · Decided by: Vlad; waiting for Gleb

## Context

"goose" came from this repository's name. It is also the name of the language
the engine is written in and of Block's AI agent, and the browser's mascot is a
boar.

## Decision

The browser is called Tusk. The engine is written in Goose; the line reads "Tusk,
on a Goose engine". The repository keeps its name for now.

## Consequences

- New code uses the name: the `tusk` command, the `tp_` prefix of the platform
  layer's C functions, the `tusk_platform` crate.
- Renaming the repository is a separate decision for the two of us.
